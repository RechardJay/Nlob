前情提要：C和C++是不同的语言，早已不是超集的简单关系，并且渐行渐远。

从结构体管中窥豹。

# C Struct

在C语言中，Struct是一种复合数据类型，你可以在里面装几个基本类型。仅此而已。

TIP：在C语言中定义和使用结构体都要提前用 `struct`关键字声明。因此常常搭配typedef 简化使用。

# CPP 面向对象

CPP对C最显著的增强即是面向对象的引入。但谈到面向对象，CPP会被误解为只用class实现了OOP的特性而struct只是C语言的遗留。

但事实是CPP的struct和C已经不是一回事了。在CPP中struct和class几乎是等价的，都具有OOP特性。二者甚至具有相同的命名空间，即无法定义同名的strcut和class。

与C的区别：CPP中，struct可以有构造、成员、函数、访问控制、继承与多态、虚函数重载等OOP的一切。且不再需要tpyedef 为结构体提名了。定义的结构体会自动成为类型名。

class 和 struct唯一的区别就是默认的访问权限不同，struct默认是pubic，而class默认是private。

因此现代CPP struct可class一样广泛使用

- struct用于数据聚合。存纯数据，少封装，少复杂行为，可公开的简单数据操作。偶尔会继承和多态。

- class用于封装对象。习惯上将数据和内部状态与操作私有，只外暴露接口。

理论上你可以只用class实现一切。但如果你想明白一个对象的责任具体，定义一个struct是很清爽的。
